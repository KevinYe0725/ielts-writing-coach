# IELTS Writing Coach v1.0.0

This is the first public release line for the self-hosted Web application and
the standalone `coach-ielts-writing` Codex Skill. Operators should pin the
`1.0.0` container tag or, preferably, the published image digest.

## Database migrations

- A fresh or pre-release database is migrated forward through the checked-in
  Drizzle lineage ending at `0011_teaching_practice_analysis` (12 application
  migrations), followed by the matching Graphile Worker migrations.
- Migration execution is serialized with a PostgreSQL advisory lock. Compose
  runs the one-shot `migrate` service before Web and Worker; Railway and Render
  run the same lock-aware wrapper as a pre-deploy command.
- The readiness endpoint remains unavailable until the exact expected
  migration count and latest migration timestamp are present. Migrations are
  forward-only, so create and verify a database plus instance-secret backup
  before deploying this release.

## Breaking changes

- There is no earlier stable IELTS Writing Coach release, so v1.0.0 has no
  supported stable-to-stable in-place upgrade source and no downgrade path.
- PostgreSQL 17, Node.js 24.14 or newer for source operation, and the v1.0.0
  learning/exchange contracts are the initial compatibility baseline.
- Rolling an older image back onto a database migrated by v1.0.0 is not
  supported. Rollback requires the matching pre-deploy database and secret
  backup described in the recovery runbook.

## Known limitations and external gates

- The automated recovery gate proves a same-build backup and clean-instance
  restore. Cross-version upgrade evidence can only be added after an earlier
  stable release exists.
- Railway remains Tier 1 only after its externally hosted template has created
  Web, Worker, and PostgreSQL with generated shared secrets and passed the
  browser and recovery acceptance checks. Repository TOML parsing alone is not
  hosted-deployment evidence.
- Render is a community-supported Blueprint. Operators must review current
  paid-plan support for pre-deploy commands, backups, pricing, ingress, and the
  selected PostgreSQL plan before using it for important data.
- Repository tests use Mock for deterministic no-cost journeys. The release
  operator must retain the dated external real-provider, human-review, cloud
  template, and manual accessibility evidence required by the release policy.

## Release artifacts and verification

- GHCR publishes `linux/amd64` and `linux/arm64` images with BuildKit SBOM and
  provenance attestations plus a GitHub artifact attestation.
- The GitHub release includes the image digest, `SHA256SUMS`, and an attested
  `coach-ielts-writing-v1.0.0.zip` archive containing the Skill, `LICENSE`, and
  `NOTICE`.
- Before rollout, verify the image digest and attestation, follow the backup
  runbook, then require `/api/v1/health/ready` to report current migrations and
  a fresh same-version Worker heartbeat.

# 作文工作区：前端改版

用户已认可页面参考及开源选型，并要求给出方案后直接执行。沿用既有隔离预览，不部署、不合并 main。

## 目标与取舍

主体是 IELTS 写作者，页面的工作是让用户继续当前作文、理解修改理由、学习再实践。选择「作文工作区」而非折叠版后台或独立课程平台：减少横向功能陈列，用清楚入口进入更深的解释。

## 页面设计

- 全局取消常驻侧边栏。顶部品牌回到今天，作文切换器提供搜索、已有作文继续入口、全部作文和新作文入口。写作／批改／提升为学习导航，更多中保留重写、对比、迁移、成长、设置。登录、账户、退出、语言和通知保持可达。
- 所有当前资源链接保留 cycle / lesson / task 身份。来自另一篇作文的缓存导航不能被带入当前作文。未准备内容有明确可用性说明，不使用假链接。
- 批改保持原文与解释双栏，桌面可拖动调宽，小屏单栏。保留原文定位、过滤、估分免责声明、全部建议、例句和重试。主要问题先呈现，重复说明删去，深入解释仍可读。
- 教学保持文章阅读，不定位原文、不强塞固定讲解模板。标题、目标、正文、目录与练习分清层级，正文约 760px 阅读宽；练习与试卷有明确入口。保留真实练习答案、解析、恢复与生成状态。
- 今天与作文列表去掉重复眉题、口号、卡片里的同义说明，保留行动、题目、期限和进度。不得删除有效题目要求或学习内容来达成简洁。

## 视觉系统

纸面 #ffffff，背景 #f6f8fb，正文 #172033，重点蓝 #1d56a0，成功绿 #2f6d5a，警示琥珀 #7c531b；错误沿用现有色。中文 Noto Sans SC，英文例句 Source Serif 4，按钮/数据 IBM Plex Sans。正文 16–18px，英文例句 20–24px，功能标签 14px，不用小字堆积解释。

标志性元素是「原文边上的修改注释」，其余界面安静。布局宽度让给内容而不是把教程正文拉成超长行。移动端导航可点击、可滚动，不仅靠快捷键。

## 开源复用决策

继续复用现有 Radix、react-markdown、Lucide 和 CSS Modules。新增 cmdk 用于作文切换、react-resizable-panels 用于批改双栏、Motion 用于选中和展开的短过渡。shadcn 仅借鉴组合模式，不生成整套样式或安装 CLI 模板。不加入富文本编辑器或付费扩展。所有采用代码保留许可证。

## 不变边界

不改服务端、AI 提示词、判分、身份权限、数据结构、计时、自动保存和草稿版本。保留所有既有路由、恢复入口和功能。系统错误不能被视觉折叠隐藏。动画尊重 reduced motion，正文不逐字播放、不滚动飞入。选择器数据仅在需要时加载，失败有恢复和全部作文入口。

## 验收

桌面 1440/1280 和移动端 390/375 宽度截图，无横向溢出或遮挡。浏览器验证跨作文身份、导航与返回、搜索选择器 Escape/焦点恢复、通知与账户菜单、双栏键盘调整、原文定位、教学练习和限时卷入口。通过相关单测、类型检查、构建和许可证检查，分别说明示例验收与真实接口覆盖，不能把示例预览称为真实账号端到端测试。
